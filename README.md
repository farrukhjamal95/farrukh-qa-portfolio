# Farrukh Jamal — QA Automation Portfolio

A responsive, single-page portfolio website built from the details in Farrukh's resume.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `farrukh-portfolio`).
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. GitHub will provide the public website URL after deployment.

## Before publishing
- Confirm that the phone number, email, location, dates, metrics, and LinkedIn URL are correct and that you want them public.
- Add a public GitHub profile link if you want one displayed.
- The project cards describe representative work from the resume; they do not claim that public source-code repositories are available.
- This package is a static website. It has not been deployed to a hosting account.


## CV download button
The top navigation includes a Download CV button. Keep `Farrukh-Jamal-CV.pdf` in the repository root alongside `index.html` so the download link works.
